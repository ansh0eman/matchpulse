# Evidence map for judges

The five dimensions have equal weight in [Microsoft's official rules, section 6](https://github.com/microsoft/insidethegamehackathon/blob/main/OFFICIAL%20RULES.md). This maps actual evidence; it does not assign a speculative competition score.

| Dimension | Implemented evidence | Demo location | Remaining gap |
|---|---|---|---|
| Technological implementation | Pinned simulator, immutable source claims, independent recomputation, browser/SDK tests, non-root packaged viewer | Goal score boundary; Proof Method/Audit | No public Azure viewer verification yet |
| Agentic design and innovation | Conditional specialist routing, challenger, model-requested evidence tools, independent branch recovery, deterministic gate; persisted fully enriched real goal artifact | Recorded successful workflow and historical recovery graphs/tool traces | Human/real-model A/B/C comparison and verified network request total remain pending |
| Real-world applicability | Machine-readable source-scoped overlays, program output, safe fallback, credential-free replay packaging | Program output; stale-evidence chapter | Public hosting, telemetry/load/operations validation pending |
| User experience and presentation | Theatre, before/after Proof Summary, progressive Method/Audit, downloaded proof receipt, Fan/Analyst, guided story, responsive tests | Four-chapter story; phone Proof Lens | Finished public video and independent usability review pending |
| Category adherence | Synthetic ingest → interpretation → explanation → timed rendering → audience/favorite-team adaptation | Theatre → Analyst → Proof Lens | English only; player focus and speech intentionally deferred |

For the multi-agent category, demonstrate purposeful handoffs and a specific recovered failure. Agent count alone does not establish value. Architecture, observations and limitations are in AGENT_CARD.md, DATA_CARD.md and EVALUATION.md. New UI evidence is in research/step3d/acceptance.md.

Release restrictions remain in force: the repository stays private until the user explicitly changes that instruction. Public hosting/video/submission are pending and must not be represented as complete.
