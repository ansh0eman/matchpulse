# Source-backed comparison, consolidated

Use the [seven pinned revisions and direct code links](../step3e/competitive-audit.md) as the evidence ledger. That fresh audit inspected implementations; this matrix adds dependency decisions instead of cloning reports. Competitor latency/evaluation numbers remain author-reported unless separately reproduced. No incompatible datasets are compared as a league table.

| Dimension | Source-backed comparison / MatchPulse boundary | Decision |
|---|---|---|
| Simulation/native tracking | MatchSense emphasizes native simulator data; Matchday Crew's full-team formation motion is client-inferred. MatchPulse has original native snapshots, but its showcased goals/tracking are separate. | Generate a new same-run showcase; preserve the distinction. |
| Statistical/tactical coverage | Existing schemas support more observed event types than the current public incident set. No calibrated xG/speed is established here. | Expand only through new verified contracts, not copied labels. |
| Incident/momentum | Our deterministic incident engine exists; a statistical definition and evaluation are needed before adding “momentum”. | Defer uncalibrated charts. |
| Orchestration/Foundry | Matchroom implements version registration. Our real app-owned MAF graph is distinct; Football Universe explicitly documents local orchestration. | Show real route/challenge/recovery; don't equate agent count with value. |
| Real-time/streaming | MatchDirector has separate fast/review lanes. Our viewer is causal replay and currently request-bound. | Repair continuity first, then bounded buffering/stream contracts. |
| Verification/hallucination | Our Proof Lens independently recomputes original positions, beyond merely checking an allowed number in prose. | Preserve as the signature; add adversarial cases for each new feature. |
| Recovery/observability | Matchroom/MatchDirector contain verifier/fallback paths. Our saved compiler rejection is genuine, not an outage. | Keep actual branch provenance and missing telemetry explicit. |
| Personalization | Competitors show player/metric/language modes. Our Fan/Analyst/favorite modes preserve verified facts. | Source-ID player slice after unified-source correctness; no cosmetic-only mode claims. |
| Graphics/motion | The Dugout has a sharply focused operator story; inferred motion cannot substitute for our observations. | Adopt clear hierarchy/story pacing, not assets or trajectories. |
| Questions | Beyond Scoreline has bounded tool-backed free text/citation checks. Our questions remain closed/deterministic. | Structured retrieval and adversarial validity before expanding generation. |
| Recaps/audio | Beyond Scoreline uses actual speech synthesis/caching. Our local licensed stock-voice demo costs no hosted inference. | Rights-cleared narration; do not claim runtime multilingual/speech service. |
| Accessibility/mobile | Public UI code/demos are leads, not our independent usability measurement. Our keyboard/reduced-motion/geometry tests exist. | Inspect actual captures and truthful nonvisual incident updates. |
| Evaluation rigor | MatchDirector includes author-recorded model latency/red-team results. Our A/B/C is offline FakeProvider engineering only. | Same-case evaluation, explicit null human/model-quality fields. |
| Production architecture | Competitors' deployment code does not prove their current tenant uptime. Our protected trial path is prepared, not accepted HTTPS yet. | Verify the exact artifact and actual public host. |
| Demo/onboarding | Memorable guided concepts outperform a wall of diagnostics. | Keep Theatre → Proof → restraint → actual agents; developer inspection is not human research. |

Additional authenticated Innovation Studio submissions were not re-audited for this consolidation. The known project session is accessible for eventual submission; that does not imply independent acceptance of competitor demos. Prioritize measured correctness and a coherent product over chasing every competitor feature.
