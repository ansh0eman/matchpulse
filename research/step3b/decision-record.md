# Persisted engineering decisions

1. Preserve all stories/tracking source, frozen configs, old UV lock and historical Step3A artifacts. New code lives in agents/. Step3A AgentOutput v1 stays unchanged; controlled studio decisions and BroadcastArtifact use schema_version2.
2. Prioritize a verified local implementation while Azure is absent. Never call fake outputs real Foundry or call the async harness Microsoft Agent Framework. Initially unavailable integration tests skipped with explicit reasons; subsequent isolated validation passes the SDK/MCP/schema tests. Both authenticated provider tests subsequently passed in a separately opted-in live run; they remain intentionally skipped in ordinary local regression runs. Earlier fake outputs retain their provenance.
3. Model outputs select bounded IDs/enums/structure; code inserts every number/name/coordinate. No factual free prose, keyword blacklist or second-model agreement is accepted as proof.
4. Publish only an existing scheduler-approved incident. Version2 audience policy hides standalone high regains for fans; analysts retain them. Facts, research alerts and old timelines are preserved. Quiet periods stay quiet.
5. Approved selection is incident-scoped. Tools can inspect bounded historical context, but this release cannot publish additional arbitrary context claims or synthesize separate incidents. Current Step3A insights each contain one claim; real examples route to one specialist. Mixed-specialist schema support is not a claim of a demonstrated multi-incident synthesis.
6. Challenger narrow forces an evidence-first structure; fallback prevents narrator invocation. One bounded review, no autonomous revision conversation. Narrator and replay failures recover independently.
7. At most6 logical role calls; at most1 application retry for transient timeout/rate-limit failures; request deadline12s and overall request budget35s by default. Tool result payload<=32768bytes, at most8 calls per incident. SDK-internal network retry behavior and cancellation timing are not verified and may add transport attempts; do not equate application counters with billed model requests.
8. New agent/credential/client per Foundry request, run-local coalescing and success cache only. Correlation hashes stay local; no remote idempotency guarantee, durable checkpoint or future-leaking memory. A timed-out request may still consume provider tokens.
9. English only. Unsupported localization is rejected. Favorite team changes editorial labels without changing source claims. Human usefulness ratings are pending; offline comparison cannot prove LLM superiority.
