# Security and integrity review

- Authority is recomputed stories/ evidence, not model text or user-supplied broadcast JSON. Runtime accepts only original scheduler-approved insight objects and their exact verified claims.
- Tools bind match/time scope, reject unknown operations/categories/arguments and future data, and bound counts/payloads. No filesystem/network/write capability is exposed to models.
- Closed immutable v2 contracts admit controlled labels/IDs only. Source-derived final compilation rejects invented numbers, scorelines, names, coordinates and causal factual prose. Deep legacy lists exist inside v1 positional values; models receive serialized JSON, never mutable Python authority objects, and final geometry is reverified.
- Endpoint configuration allows HTTPS commercial Azure project endpoints only, without embedded credentials/query/fragment. Real provider exceptions are normalized; no raw bodies/headers are exported. .env and isolated environments are ignored. No keys or tokens were created/read into output.
- Separate requests/agents per incident, no durable shared conversations or model-accessible arbitrary memory. Cache coalesces identical run-local successful requests. Remote billing/idempotency and SDK-internal retries remain unproven.
- Optional MCP is private stdio, no HTTP listener. Cloud SDK packages are now installed only in the isolated environment and pass the non-live suite; no frozen lockfile was changed. Package/runtime compatibility evidence is not a complete supply-chain audit or live authorization proof.
- Failed narration and overlays fall back independently. Corrupted authority fails closed before any publication. No new deployment, resource creation, external match web search or third-party messages occurred.

Adversarial tests cover cross-match/future references, missing IDs, oversized results, malformed JSON, unsupported tools/prose, altered numbers/coordinates/clocks, retry budgets, timeout/auth/rate-limit failures, unchanged facts across preferences and session isolation. Tests are finite engineering evidence, not a universal security proof.


Subsequent setup/live validation used Entra AzureCliCredential with no API-key export, and provider lifecycle/instructions were repaired while deterministic validators remained intact. This documentation turn preserved that source and performed no paid calls, provisioning, publication or tests. Trial spending protection is a coordination management checkpoint, not re-queried here. Developer login must not become public hosting authentication.
