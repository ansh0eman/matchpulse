## Ready-to-use pitch

MatchPulse AI turns synthetic football observations into explanations a viewer can inspect. Its broadcast studio synchronizes match clocks, score snapshots, observed positions and personalized stories. Proof Lens goes beyond a citation: it recomputes an explanation from original source events or player coordinates, exposes the calculation and tells you when the evidence is too stale to speak. Microsoft Agent Framework coordinates specialist roles using an authenticated Microsoft Foundry model and bounded evidence tools; deterministic validation checks the resulting narrative and replay plans before publication. The demo includes a genuine recorded recovery case where safe narration survives an invalid model plan. Fan and Analyst modes change detail while preserving the facts.
