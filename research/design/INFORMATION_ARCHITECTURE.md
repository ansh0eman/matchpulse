# Information architecture

**Matchday** is the default viewing experience, starting native-goals at1611s (0–0). The first observed goal is at1614s. **Analysis Room** names the existing detailed Studio; it retains all restricted questions, recaps and audience controls. **Proof Lens** remains a contextual action on an eligible moment. **Agent room** retains genuine saved execution and advanced details; no live-model activity is simulated.

Other matches are quieter text navigation under the main experience. The verified positional example and stale-evidence refusal remain separate sources. Chronology selects only currently available incidents, sorts presentation time then existing engine priority, and lets the user revisit a moment. Current explanation shows its own source timestamp, so a historical shot is not presented as occurring at the current playhead.

Existing view=studio/theatre/broadcast links work. The URL now retains the allowlisted scenario; reload returns to that scenario's declared starting point. Playback clock is not written into history every tick. Native goal, original goal, equalizer, open-play, position and refusal sources are not merged.
