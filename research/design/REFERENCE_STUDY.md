# Reference study and hackathon scope

October 24, 2026. The latest user direction narrows design work to a professional laptop experience and usable mobile layout, then submission readiness and the highest-value engineering work. The comprehensive six-viewport redesign is superseded by this bounded gate. [Official rules §6](https://github.com/microsoft/insidethegamehackathon/blob/main/OFFICIAL%20RULES.md#6-judges--criteria) weight UX/presentation at20%, alongside implementation, agentic innovation, applicability and category fit. A separate native mobile product is not prescribed.

| Reference | Actual access / useful principle | Applied decision / restriction |
|---|---|---|
| [StatsBomb IQ Live](https://blogarchive.statsbomb.com/news/an-introduction-to-our-iq-live-platform-announcing-statsbomb-matchdays/) | Read public article: incident, spatial context and audience-facing explanation belong together. | Pitch and timestamped explanation share a stage; no borrowed xG model or professional-feed claim. |
| [Hudl Sportscode](https://www.hudl.com/products/sportscode) | Public workflow description: timeline precision and linked video/data. No authenticated software session tested. | Persistent replay transport and moment selection; no video-editing features claimed. |
| [Hudl / Wyscout](https://www.hudl.com/) | Public product navigation/descriptions reviewed; no paid scouting account used. | Deeper tools live in Analysis Room, separate from the fan opening. No invented player ratings. |
| [Matchboard](https://dribbble.com/shots/27235118-Matchboard-Football-Match-Dashboard) | Public description and actual monitor imagery inspected in browser. | One main spatial surface linked to chronology. Reject equal dashboard panels and unsupported xG/avatars. |
| [Match Zone](https://dribbble.com/shots/27043360-AI-Powered-Football-Match-Zone) | Actual image opened in browser: athlete-led focal composition. | Spend visual emphasis on the real pitch; do not reuse athlete photography, glass panels or speculative metrics. |
| [Scouting Analytics](https://dribbble.com/shots/27180578-Football-Scouting-Analytics-Dashboard) | Public text reviewed; imagery not independently inspected in this pass. | Filtering/comparison is an analysis workflow lead, not proof of usability. |
| [Live Match App](https://dribbble.com/shots/26643988-Football-App-UI-Live-Match-App) | Public text reviewed; imagery not independently inspected in this pass. | Mobile order: score, pitch, explanation, evidence and controls. |
| [DaVinci Resolve Edit](https://www.blackmagicdesign.com/products/davinciresolve/edit) | Official timeline/transport documentation reviewed. | Source-derived event ticks accompany the native replay slider; no new editing service. |

No third-party design code, images, footage, logos or proprietary assets were copied. Public concept descriptions are not independent usability evidence. Existing source-backed competitor findings remain in `research/step3e/competitive-audit.md`; this work addresses their linked-view/navigation benchmark without adopting unsupported features.

The requested frontend-design, webapp-testing and vercel-react-best-practices skills were installed globally under ~/.codex/skills from pinned official upstream revisions. The preexisting web-design-guidelines matches Vercel upstream. Their instructions were read; no installer scripts from those repositories were executed. Existing fonts/icons and notices are retained.
