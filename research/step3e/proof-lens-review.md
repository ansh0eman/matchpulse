# Proof Lens: understand, reproduce, audit

The redesigned presentation leaves `viewer.proof.receipt` and every analytical module unchanged. Each proof request still checks match/time/audience eligibility and recomputes independently from canonical observations. The browser is not a source of mathematical authority.

| Level | Experience | Source boundary |
|---|---|---|
| Summary | Two original frames, highlighted contributors, before/after means and prominent delta | Representative snapshots illustrate; they are not the aggregate calculation |
| Contributor inspection | Expand “Which players contributed…” to see six original player IDs, x/y, attack-relative x and each snapshot proxy | Values come directly from the verified receipt's selected samples; IDs are not shirt numbers |
| Method | Windows, three-deepest-outfield definition, attack-relative geometry, context weights, counts and evidence age | Similar observed contexts are compared; no tactical intent is inferred |
| Audit | Original observations, frame/event IDs, all samples, namespace, hashes and downloadable JSON receipt | Future/cross-match/unknown references remain rejected |

Exact preserved result: **21.951300813008128m → 31.96388888888889m**, difference **10.01258807588076m**; **41** reference and **18** recent frames, **59** total. Display rounding is 21.95 →31.96, +10.01m. Highlighting finds contributors by the actual representative frame ID, not a fabricated formation.

Observed: the sampled three deepest outfielders were farther forward in comparable contexts. Not established: a manager ordered a high press, pressure worked, or this result calibrates real football. The separate stale fixture with **132s** old evidence continues to withhold the positional claim.

`ProofSummary` downloads the actual verified server response; it does not assemble a new numerical receipt. `App` aborts old proof requests and clears prior context on seek/fixture/audience changes. `ProofLens` retains Summary → Method → Audit, Escape/focus handling and loading/error controls. Reduced-motion removes reveal animation; no measured trajectories are implied.

Verification is in backend/tests/viewer/test_viewer.py and web/tests/{broadcast,theatre,experience}.spec.ts. The new contributor count, keyboard entry, non-overlap, same-fixture reload and backward-seek cases complement the original numerical, corrupted-source and match-isolation tests. Completed outcomes, screenshots and limits belong in browser-acceptance.md.
