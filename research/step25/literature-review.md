## Metrics considered and what is observable here

Line height: deepest-three outfield mean, deepest-four mean and 20th percentile; goalkeeper is explicitly excluded rather than assumed to be the deepest dot. Line of confrontation cannot be directly observed as a coach's chosen boundary; carrier-near defenders and advanced-player occupancy are spatial proxies. Nearest defender distance and density within 5/10/15m describe geometry, not effective pressure by themselves. Team length/width, centroid, dispersion and an inter-quantile line-gap proxy describe organization without revealing formation targets.

High recoveries are retained as action counts; only an opponent-to-team possession transition would justify “turnover.” Opponent build-up disruption requires comparable opponent possessions and honest pass-attempt/completion semantics. Field tilt and progression are event proxies when endpoints are absent. Counterpressing requires a defensible possession-loss clock and short post-loss exposure; no hidden loss/press intent is supplied. Synchronization would require displacement/time-series coupling across players; it is not approximated by a one-frame density count. Those higher-complexity metrics are not silently substituted for implemented geometry.

## Statistical methods and shortlist

[NIST CUSUM](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc313.htm) motivates accumulation of sustained deviations; [NIST EWMA](https://www.itl.nist.gov/div898/handbook/pmc/section3/pmc324.htm) motivates weighted smoothing. Industrial control assumptions do not establish football false-alarm probabilities. Period transitions, possession, score and repeated overlapping checks create nonstationarity and dependence. We therefore compare context-conditioned clock windows and a bounded sequential alternative on whole-match null cases, without interpreting repeated checks as independent hypothesis tests.

Page-Hinkley/ADWIN were already compared in Step 2 using event signals. They are not assumed to fix information loss. Offline PELT can describe complete series retrospectively, but cannot establish live detection. Nonparametric ranks are used for development distribution separation, with seed-family resampling. Covariance-sensitive multivariate methods risk redundant spatial features and too few independent families. Bayesian online change points add hazard/prior choices and cost without first proving separability; no neural network is justified.

A small regularized classifier is eligible only if development feature separation is credible. Development/validation/holdout families stay disjoint; at most a few features and fixed time examples per match avoid pretending overlapping frames are independent samples. [Grouped cross-validation guidance](https://scikit-learn.org/stable/modules/cross_validation.html#group-k-fold) supports keeping repeated observations from the same group together. We can implement a tiny L2 logistic fit using already-installed numerical libraries; no new large ML dependency is necessary. Its sigmoid is not a calibrated broadcast confidence without independent calibration evidence.

Priorities: (1) validate observable tracking, (2) paired feature separation relative to null variation, (3) interpretable conditioned comparison and event baseline, (4) fused/sequential alternatives, (5) small supervised ablation only if the separation gate supports it. Competitor implementations are inspected conceptually in competitive-comparison.md, with licenses and file hashes; no application source is copied.
