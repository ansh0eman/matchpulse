# React broadcast contract

Read TimelineItem.schema.json and the timeline.json array. Use presented_at_seconds to reveal items; jump-to-source uses insight.event_time_seconds. Score bug uses observed_score from canonical observations, not card counts. Each item embeds fallback headline/explanation, editorial priority, claim IDs, reference namespace, limitations and provenance. Full precision typed facts are in claims.json; evidence-index.json resolves match-scoped events/frames. summary.json includes input hashes; exports are deterministic JSON, not a live REST service.

Visualization: event_location uses actual ball coordinates from referenced event, scoreline uses observed score, window_comparison uses typed windows/counts, tracking_comparison uses referenced before/recent frames and the three-deepest-outfielder proxy. Never infer an unobserved pass endpoint or player trajectory. Animation between tracking observations is visual interpolation, not evidence. Do not confuse actor location with event ball location.

Fan/analyst modes share the same authoritative facts; fan shows concise fallback and limitation badge, analyst shows units, support, exact windows and recomputation definitions. Evidence inspector resolves category+source ID within match UUID. Recap can select chronological verified insights; no causal connective or coach-intent prose is authorized. Raw research detections and unscreened .facts.json must never become broadcast cards. Missing tracking simply omits positional cards. Clearly label all matches fictional/synthetic and uncalibrated.
